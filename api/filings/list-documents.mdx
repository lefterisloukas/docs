---
title: "List filing documents — GET /v1/filings/{id}/documents"
description: "List all documents and exhibits attached to an SEC filing. Returns document IDs, descriptions, content types, and sequence numbers."
---

Use this endpoint to retrieve the full document index for a filing. Each item in the response represents a single file attached to the filing — such as the primary report, exhibits, or XBRL instance documents. The `document_id` returned here is the key you pass to the [get document](/api/filings/get-document) endpoint to fetch raw content.

## Endpoint

```
GET /v1/filings/{accession_number}/documents
```

## Authentication

All requests require a Bearer token in the `Authorization` header:

```bash
Authorization: Bearer hv_live_<your_key>
```

A missing or invalid key returns `401 unauthorized`.

## Path parameters

<ParamField path="accession_number" type="string" required>
  The SEC accession number with dashes, in the format `XXXXXXXXXX-XX-XXXXXX`. For example, `0000320193-23-000106`.
</ParamField>

## Response

A successful request returns a `DocumentPage` object with a `200` status. All documents for a filing are returned in a single page.

<ResponseField name="results" type="DocumentSummary[]">
  Array of documents attached to the filing.

  <Expandable title="DocumentSummary properties">
    <ResponseField name="document_id" type="string">
      The document filename (e.g. `aapl-20230930.htm`). Pass this value as the `document_id` path parameter when calling `GET /v1/filings/{accession_number}/documents/{document_id}`.
    </ResponseField>

    <ResponseField name="description" type="string">
      A short description of the document's role in the filing (e.g. `10-K`, `EX-21.1`). May be an empty string if the SEC filing index does not include a description.
    </ResponseField>

    <ResponseField name="content_type" type="string">
      The MIME type of the document (e.g. `text/html`, `application/xml`). May be an empty string if the content type is not specified in the filing index.
    </ResponseField>

    <ResponseField name="sequence" type="integer | null">
      The sequence number assigned to this document in the SEC filing index. `null` if no sequence number is present.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="total" type="integer">
  Total number of documents in the filing.
</ResponseField>

<ResponseField name="page" type="integer">
  Current page number. Always `1` for this endpoint.
</ResponseField>

<ResponseField name="pages" type="integer">
  Total number of pages. Always `1` for this endpoint.
</ResponseField>

<Tip>
  Use the `document_id` from this response as the `{document_id}` path parameter in `GET /v1/filings/{accession_number}/documents/{document_id}` to fetch the raw content of any document.
</Tip>

## Errors

| Status | Code | Description |
|--------|------|-------------|
| `401` | `unauthorized` | Missing or invalid Bearer token. |
| `404` | `not_found` | No filing found for the given accession number. |

All error responses use the standard envelope:

```json
{
  "error": {
    "code": "not_found",
    "message": "Filing not found.",
    "details": {}
  }
}
```
